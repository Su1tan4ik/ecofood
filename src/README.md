# 📁 src/ — Исходный код для разработки

Здесь лежит **разделённая версия** платформы — HTML, CSS и JS в отдельных файлах. Удобно для разработки и понимания структуры.

## Структура

```
src/
├── index.html      # разметка
├── styles.css      # все стили
└── app.js          # логика, данные, обработчики
```

## Как запустить локально

```bash
# Способ 1 — через Python
cd src
python3 -m http.server 8000
# открой http://localhost:8000

# Способ 2 — через npx (если установлен Node.js)
npx serve src

# Способ 3 — двойной клик по src/index.html
```

## Связь с корневым `index.html`

В корне репозитория лежит **собранная версия** — всё в одном файле для GitHub Pages. После изменений в `src/` обнови корневой `index.html` (склей вручную или через скрипт сборки).

## Что куда

| Хочешь изменить | Файл |
|---|---|
| Цвета, шрифты, отступы | `styles.css` (CSS-переменные в `:root`) |
| Тексты, разметку | `index.html` |
| Список объявлений, фильтры, формы | `app.js` (`sampleListings` — массив с данными) |
| Логику бронирования / модалок | `app.js` (`openModal`, `reserveListing`) |
